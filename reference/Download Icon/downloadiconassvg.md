## 🟪 Why icons in SVG format ?

### ✅ Best for UI and web

* They scale without losing quality on any screen (great for retina/high-DPI displays)
* Easily styled with CSS (color, size, animation)
* Smaller file size for simple icons (especially line/mono styles)
* Great for accessibility (\<title> and aria-label ready)

### 🔁 Use when you need:

* Responsive layouts
* Dynamic theming (e.g., dark/light mode with fill/stroke)
* Crisp icons at any size
* Embedding directly in HTML or CSS
